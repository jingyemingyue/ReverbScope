# Claude Code

Follow [AGENTS.md](AGENTS.md).

The execution standard is
[docs/GUIDELINES.zh-CN.md](docs/GUIDELINES.zh-CN.md) (v2.1.3).
[docs/GUIDELINES.md](docs/GUIDELINES.md) is an English summary. If they
differ, the Chinese text wins. How AI help is used is
[docs/AI_ASSISTANCE.md](docs/AI_ASSISTANCE.md).

One task, one branch, one pull request. Do not open a second GUI redesign.
Do not merge, publish, tag, or close a pull request, except that the
maintainer may explicitly ask in the session for a patch or regular update
release (see Releases in AGENTS.md). Do not put an email
address, an organization id, or a token in the tree. Do not edit the
guidelines; write a guidelines-change proposal instead, unless the
maintainer explicitly asks in the session for the edit (see AGENTS.md).
