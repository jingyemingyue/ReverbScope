## 离屏基线矩阵与初始性能

`scripts/render_gui_baseline.py` 支持 main 和 #58 的两种窗口接口。每个语言、
主题、DPR 组合使用新进程、临时设置和 fake 后端。截图附合成标记、源提交；
JSON 记录请求尺寸、实际逻辑尺寸、图片像素和 DPR。四种主窗口尺寸均准确，
设置对话框则记录其自身尺寸。该脚本不操作声卡，不污染真实最近列表。

| 指标（中位数） | main `3567da0` | #58 `2560124` |
| --- | --- | --- |
| 源码导入到首次离屏窗口 | 1.585 s | 2.003 s |
| 打开一次测量并处理界面事件 | 0.534 s | 0.129 s |
| 切换视图并处理界面事件 | 48.3 ms | 32.6 ms |
| 最慢一次视图切换 | 167.9 ms | 3486.1 ms |
| 截图数（32 种尺寸/语言/主题/DPR 组合） | 448 | 544 |

环境：Apple Silicon，macOS 27.0.1，Python 3.12.14，PySide6 Essentials
6.11.2。使用独立的已预热字体缓存；全量测试同时运行，因此这些数据是基线
观察，不是受控性能验收。异步频谱另外等实际结果完成后截图；切换计时只包括
切换动作和界面事件处理。首次重绘的长尾需要后续阶段处理。没有测量打包版
冷启动、3 条曲线缩放帧率、20 次测量加载、Retina 或触控板。

归档交付名称：`ReverbScope-Phase0-992张基线截图.zip`，包含两套截图、16 份
逐组合清单、汇总数据和原始准则 v1.0。完整矩阵复现时分别使用两个源码 checkout：

```bash
python scripts/render_gui_baseline.py --source /path/to/checkout --demo /path/to/synthetic-project --out /path/to/new-output --revision 2560124b3875112995eda021f46a7da7c772f9bc --lang zh_CN --scheme light --scale 1
```

对 `en/zh_CN`、`light/dark`、`1/2` 各组合重复；脚本每次自动覆盖四个尺寸。
`--revision` 必须与所选 checkout 的实际提交相符；本次每个原始 ref 均已核对。
