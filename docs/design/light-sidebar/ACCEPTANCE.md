# 浅色侧栏基线 · 验收标准

用于验收**按本基线实现的代码**（不是验收这些设计稿）。每条都要能用离屏截图、Qt 交互脚本或真机手测证明；证据类型沿用 PR #89 验收报告（实际交互 / 视觉观察 / 静态代码）。
尺寸：960×640、1280×800、1440×900；语言 zh_CN / en；主题浅 / 深。下表“全矩阵”= 3 尺寸 × 2 语言 × 2 主题。

## A. 外观基线（VIS）

| ID | 标准 | 怎么验 |
|---|---|---|
| VIS-01 | 颜色只来自 SPEC §2 token；浅色画布 `#FBFAF8`、侧栏渐变/材质、唯一强调色 teal | 静态：grep 硬编码颜色；截图取色 |
| VIS-02 | 文字对比 ≥ 4.5、曲线/坐标轴/控件边框 ≥ 3.0（浅、深都测）；跑 `source/contrast.py` 的同类检查在 CI 中通过 | 脚本 |
| VIS-03 | 页面只有一层卡片（分组列表）；图表外没有卡片；警告是卡片底部满宽色带 | 截图 |
| VIS-04 | 所有间距是 4 的倍数且出自 SPEC §4；控件高 28，工具栏 52，操作栏 64 | 截图量 + 布局断言 |
| VIS-05 | 字体层级按 SPEC §3；数字用等宽或表格数字；负号为 “−” | 截图 |
| VIS-06 | 合成 / 演示数据时，测量页工具栏和分析页页头都有“合成演示数据”标签 | 截图 |

## B. 图标（ICON）

| ID | 标准 |
|---|---|
| ICON-01 | 只用 Lucide（lucide-static 1.59.0 或之后同一主版本），线宽 1.5 px（按尺寸换算），尺寸只有 14/16/18/20 |
| ICON-02 | SPEC §16.2 中每个图标都接到表里的那个功能；没有无功能的图标（首页说明除外） |
| ICON-03 | 默认 / 悬停 / 激活 / 禁用 / 危险五态与 SPEC §16.1 一致；禁用图标用 `disabled` 色 |
| ICON-04 | 图标与文字间距 6–8 px，垂直居中对齐文字中线（截图叠参考线检查） |
| ICON-05 | 第三方许可证窗口列出 Lucide（ISC）与 Feather（MIT）全文 |

## C. 布局（LAY）

| ID | 标准 |
|---|---|
| LAY-01 | 全矩阵下：频响主图坐标轴单位、刻度、读数栏、Stop、操作栏主按钮均不被裁切；按钮 `sizeHint().width() <= width()` |
| LAY-02 | 960×640 频响主图（PlotWidget）高度 ≥ 窗口高度 50 %，且与测试执行顺序无关（修 CI-01 的顺序依赖） |
| LAY-03 | 断点行为按 SPEC §13：< 1100 侧栏隐藏为覆盖层；< 1440 检查器覆盖式且不遮读数栏；960 下分段只显示 4 个 + “⋯” |
| LAY-04 | 没有上下文栏 / 状态栏；工具栏一层 52 px；短暂提示（保存成功等）在工具栏副标题位可见 ≥ 3 s（修 LAYOUT-R2） |
| LAY-05 | 测量页操作栏内容左右端与表单列对齐（宽屏下上一步与主按钮距离 ≤ 表单宽 + 就绪栏宽 + 48） |

## D. 忙碌（BUSY）

| ID | 标准 |
|---|---|
| BUSY-01 | 发声时：设置 ⌘,、打开 ⌘O、打开项目 ⇧⌘O、新测量 ⌘N、**保存 ⌘S**、路径分段 / ⇧⌘1 / ⇧⌘2、用户类型切换、步骤 1–2、上一步 全部禁用；按键、菜单、工具栏三种入口都**零模态** |
| BUSY-02 | 禁用项在菜单和侧栏里都能看到原因（菜单 tooltip 可见或副标题），文案“测量进行中” |
| BUSY-03 | 发声时可浏览其他测量的分析页和侧栏；切到任何页面 Stop 都可见（`visibleRegion` 非空，不在滚动区） |
| BUSY-04 | 关闭项目 / 对比会话 / 退出 在发声时的行为由维护者确认后写进测试（PR #89 BUSY-04） |

## E. Esc（ESC）

| ID | 标准 |
|---|---|
| ESC-01 | 发声中，任意下拉弹层 / 菜单 / 覆盖层打开时，**按一次 Esc** 停止并静音；停止后弹层也关闭 |
| ESC-02 | 分析中 Esc 不停止，显示“分析不可取消” |
| ESC-03 | 空闲时普通对话框（QMessageBox、设置窗口）里 Esc 关闭该对话框，背后页面和抽屉不变（修 ESC-R1）；有测试：向导页上开 QMessageBox → Esc → 对话框关闭、页面未变 |
| ESC-04 | 其余顺序按 SPEC §14：手势 > 弹层 > 覆盖层 > 向导退出（不是上一步）> 无操作 |

## F. 电平安全（SAFE）

| ID | 标准 |
|---|---|
| SAFE-01 | 电平 > −12 dBFS 且未勾选时，“继续 / 开始测量”禁用，原因写在操作栏（不只在悬停）；⌘↩ 无效；不弹框 |
| SAFE-02 | 原因文字与复选框文字逐字一致（“我已调低监听音量”） |
| SAFE-03 | 确认在以下情况被清除：电平任何改动（或维护者选定的“跨门槛”口径，D-7）、新测量、停止、完成、失败 |
| SAFE-04 | 确认被清除时若在第 3 步，回到第 2 步并显示原因 |
| SAFE-05 | ≤ −12 dBFS 时复选框禁用并显示“当前电平无需确认” |
| SAFE-06 | 键盘可完成：Tab 到复选框、空格勾选、⌘↩ 或焦点在主按钮时 ↩ 前进（KEY-01） |

## G. 流程（FLOW）

| ID | 标准 |
|---|---|
| FLOW-01 | 前一步不完整时后续步骤不可点，悬停写原因；第 1 步无设备时“继续”禁用并写原因（修 FLOW-03） |
| FLOW-02 | 每个向导页只有一个“上一步”，没有“返回” |
| FLOW-03 | 操作栏固定在滚动区外；三档尺寸 × 每一步都可见；滚到顶/底位置不变 |
| FLOW-04 | 发声时只有一个 Stop 可见（测量页在操作栏，其他页在工具栏右侧） |
| FLOW-05 | DAW 4 步与接口 3 步使用同一步骤条组件和同一门控规则 |

## H. 图表（CHART）

| ID | 标准 |
|---|---|
| CHART-01 | 频率轴为对数，主刻度 20…20k（1-2-5），次网格为十倍程内整数；倍频程图主刻度 63…8k |
| CHART-02 | 每个坐标轴标题带单位；刻度用等宽数字 |
| CHART-03 | 当前 = 实线 2 px 最上层；基准 = 虚线 [5,3] 1.5 px（按角色，不按颜色序号）；差值单独颜色 |
| CHART-04 | 扫频范围外斜线 + 注脚；Schroeder 图有评估带、拟合线（含端点）、截断斜线 |
| CHART-05 | 十字线在每条可见曲线上打点，读数栏同步显示 x、各曲线值和 Δ |
| CHART-06 | 不可靠的分频带值用 `(值)?` + 警告色 + 原因提示；不画误差线 |
| CHART-07 | 每个图表有 `accessibleDescription` |

## I. 用户类型（MODE）

| ID | 标准 |
|---|---|
| MODE-01 | 三种类型下同一测量的所有数值、单位、有效性、阈值、严重度排序完全一致（快照对比）；用户类型在代码里**未实现**，以下仅在实现后适用 |
| MODE-02 | 解释方式与默认细节按 SPEC §15 变化；安全确认与合成数据标注不随类型删减 |
| MODE-03 | 用户类型在发声时不可切换 |

## I2. 发声安全（OUT，维护者规则 2026-10-19）

| ID | 标准 | 怎么验 |
|---|---|---|
| OUT-01 | “信号与电平”及任何检查步骤**不发声**：进入、修改电平、勾选确认都不打开输出流 | 用假后端记录 `play`/输出流打开次数 = 0，直到点“开始测量” |
| OUT-02 | 输出设备列表没有“系统默认”项；扫频只送到用户选中的设备 + 输出声道；所选设备消失时停止并要求重选，不回退 | 单测：枚举列表无 default 项；拔除设备事件后 `measure` 不启动 |
| OUT-03 | 进入任何步骤、切换路径、恢复会话、打开页面都不自动播放 | 遍历所有页面切换，输出流打开次数 = 0 |
| OUT-04 | 未选输出时“继续 / 开始测量”与 ⌘↩ 禁用，操作栏原因“先选择音频接口的输出，才能继续”，就绪检查首行“未选择输出：不会发声” | 截图对照 02b；`isEnabled()==False` |
| OUT-05 | 测量中说明行写出实际出声的设备与声道，且与选择一致 | 截图对照 04 |
| OUT-06 | DAW 路径全程不发声，只写文件 | 假后端计数 = 0 |

## I3. 第 2 轮：设计稿与代码一致（GROUND）

| ID | 标准 |
|---|---|
| GROUND-01 | 工具栏分段与 `VIEW_GROUPS` 一致（总览·频率·时间·衰减·频谱·房间·对比·报告），名称用 `locale/zh_CN` 译文 |
| GROUND-02 | 每个控件都能在 FEATURES.md 找到源码出处；没有 ⌘K 搜索、反馈、V/H/Z 工具模式、叠加/差值分段、实时输入波形/电平表、GUI 导入 IR、示例项目、拖放录音 |
| GROUND-03 | 默认值与代码一致：分析平滑 1/6；瀑布 窗口 300 ms / 上升 0.5 ms / 步长 10 ms / 切片 30 / 平滑 1/12 / 立体开；时频谱 20 ms / 2 ms / 500 ms / −80 dB；扫频 20 Hz–20 kHz、10 s、−12 dBFS（独立模式 −20 dBFS） |
| GROUND-04 | 非 VALID 值用括号显示（`Values in brackets are shown, not trusted`），不是 `?`；噪声永远标“未校准 dBFS” |
| GROUND-05 | 检查器六段顺序同 `ui/inspector.py` |
| GROUND-06 | 每个图标在 SPEC §16.2 有对应的代码功能；`source/icons_used.json` 不含已删除图标 |
