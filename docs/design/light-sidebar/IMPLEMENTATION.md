# 浅色侧栏 GUI 实现对照 · IMPLEMENTATION

> 分支 `gui/light-sidebar-impl`（基于 `gui/remove-3d-room`，即 #95）。本文把
> [FEATURES.md](FEATURES.md) 里的每一项能力对到实现后的界面位置，再列出每个
> Lucide 图标对应的动作。FEATURES.md 是设计基线分支
> `design/light-sidebar-baseline`（#91）上的盘点，原样复制到这里以便链接。
>
> 位置写法：**侧栏**（左栏）、**工具栏**（52 px 统一工具栏，含分段视图组）、
> **检查器**（右栏，宽度 < 1100 px 时默认收起）、**测量栏**（底部的设备与
> 开始/停止条）、**菜单**（文件 / 视图 / 测量 / 帮助 / 开发者）、**起始面板**、
> **独立模式页**、**DAW 模式页**。快捷键写 Windows/Linux 形式，macOS 上
> Ctrl 显示为 ⌘。
>
> 截图在 [docs/images/gui-light-sidebar/](../../images/gui-light-sidebar/)，由
> `scripts/render_gui_light_sidebar.py` 离屏生成（合成演示数据和桩音频接口，
> 不是硬件测试）。

## 状态说明

- **GUI**：桌面界面里有入口，可以操作。
- **CLI**：只在命令行，GUI 不画入口（与 FEATURES.md 一致）。
- **已移除**：#95 把房间视图、扫描导入和示例房间整体删掉了（纯测量工具）。
- **未实现**：代码里没有，界面上也不画。

## 图标 → 动作

全部来自 Lucide（ISC 许可，见 `packaging/licenses/lucide-LICENSE.txt` 与
`docs/DEPENDENCIES.md` §4a），路径嵌在 `src/reverbscope/ui/icons.py`，按主题
着色，不打包字体或其他图标集（D-2、D-3）。

| 图标 | 位置 | 动作 |
|---|---|---|
| `plus` | 侧栏「新测量」 | 回到起始面板开始新测量（Ctrl+N）；运行中换成 `lock` |
| `lock` | 侧栏「新测量」；步骤条 | 运行中锁住（BUSY）；步骤尚不可用 |
| `layers` | 侧栏、起始面板「打开项目…」 | 打开或新建项目文件夹（Ctrl+Shift+O） |
| `folder` | 侧栏、起始面板「打开会话…」 | 打开 session.json 或其文件夹（Ctrl+O） |
| `history` | 侧栏 ▸ 已保存的会话 | 打开最近的会话 |
| `settings` | 侧栏底部「设置…」 | 设置对话框（Ctrl+,） |
| `circle-help` | 侧栏底部「首次测量说明」 | 首次测量说明与用户指南 |
| `stethoscope` | 侧栏底部 | 环境报告（报 bug 用） |
| `panel-left` | 工具栏左 | 显示 / 隐藏侧栏（Ctrl+Shift+Left） |
| `panel-right` | 工具栏右 | 显示 / 隐藏检查器（Ctrl+Shift+Right） |
| `save` | 工具栏右 | 保存会话（Ctrl+S） |
| `folder-open` | 工具栏「项目」 | 项目视图（Ctrl+8） |
| `chevron-down` | 工具栏（窄窗口） | 视图组放不下时列出全部视图 |
| `audio-lines` | 起始面板卡片「音频接口」 | 独立模式页 |
| `music` | 起始面板卡片「DAW 录音」 | DAW 模式页 |
| `git-compare` | 起始面板「对比两个会话…」 | 对比视图 |
| `mic` | 起始面板底部 | 录音配置说明（只是标记） |
| `sliders-vertical` | 测量栏「设置…」 | 打开当前模式的设置页 |
| `square-stop` | 测量栏、独立模式页「停止」 | 停止并静音输出（Esc） |
| `chevron-left` | 独立模式页「返回」 | 回到之前的视图；没有打开的测量时回到起始面板 |
| `check` / `activity` | 步骤条；复选框 | 已完成 / 进行中 |

`icons.py` 里还嵌着设计稿 SPEC 列出的其余 Lucide 图标（如 `arrow-left-right`、
`cable`、`chart-spline`、`copy`、`download`、`file-text`、`ruler`、
`triangle-alert`），目前没有控件使用；它们同属 Lucide，留给后续按 SPEC 接入，
不涉及新的许可。

## 与设计稿不同的决定

- D-4：保留分段视图组（总览、频率、时间、衰减、频谱、对比、报告），去掉
  “房间”；项目不进分段组，单独一个按钮，Ctrl+8。
- D-8：侧栏、检查器开关仍是 Ctrl+Shift+Left / Right。
- D-7：任何电平改动都清除电平确认。
- D-2 / D-3：不打包字体；只用 Lucide。
- 保留状态栏；检查器停靠在右侧，窗口宽度 < 1100 px 时收起。
- 步骤条是就绪指示，不拆成单独的向导页。
- 合成演示和 fake 后端不受“必须选择输出”的限制。
- SPEC §14 的 Esc 优先级顺序没有实现（Esc 目前只停止测量）。
