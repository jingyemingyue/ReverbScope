# 浅色侧栏 GUI 实现对照 · IMPLEMENTATION

> 分支 `gui/light-sidebar-impl`（基于 `gui/remove-3d-room`，即 #95）。本文把
> [FEATURES.md](FEATURES.md) 里的每一项能力对到实现后的界面位置，再列出每个
> Lucide 图标对应的动作。FEATURES.md 是设计基线分支
> `design/light-sidebar-baseline`（#91）上的盘点，原样复制到这里以便链接。
>
> 位置写法：**侧栏**（左栏）、**工具栏**（52 px 统一工具栏，含分段视图组）、
> **检查器**（右栏，宽度 < 1100 px 时默认收起）、**测量栏**（底部的设备与
> 开始/停止条）、**菜单**（文件 / 视图 / 测量 / 帮助 / 开发者）、**起始面板**、

> Ctrl 显示为 ⌘。
>
> 截图在 [docs/images/gui-light-sidebar/](../../images/gui-light-sidebar/)，由
> `scripts/render_gui_light_sidebar.py` 离屏生成（合成演示数据和桩音频接口，
> 不是硬件测试）。

## 与设计稿不同的决定

- D-4：保留分段视图组（总览、频率、时间、衰减、频谱、对比、报告），去掉
  “房间”；项目不进分段组，单独一个按钮，Ctrl+8。
- D-8：侧栏、检查器开关仍是 Ctrl+Shift+Left / Right。
- D-7：任何电平改动都清除电平确认。
- D-2 / D-3：不打包字体；只用 Lucide。
- 保留状态栏；检查器停靠在右侧，窗口宽度 < 1100 px 时收起。
- 步骤条是就绪指示，不拆成单独的向导页。
- 合成演示和 fake 后端不受“必须选择输出”的限制。
- SPEC §14 的 Esc 优先级顺序没有实现（Esc 目前只停止测量）。
- 短暂提示按 SPEC §6 进工具栏副标题位置；窗口窄到工具栏不显示标题时（如
  960 px 且检查器打开），同一句话浮在工具栏下方、画布上方，不抢焦点，可关闭。
- 等宽字体（读数、刻度、检查器关键数值）按 SPEC §3 的顺序取已安装的第一个，
  在 SPEC 的 SF Mono → IBM Plex Mono → Menlo → Consolas 之后补了
  Cascadia Mono、DejaVu Sans Mono、Liberation Mono（Linux 常见）；一个都没有
  时保持界面字体。大数字仍用界面字体（SPEC 的 num）。
