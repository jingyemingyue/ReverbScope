# ReverbScope 浅色侧栏基线 · 视觉规格（设计稿规格，不是实现说明）

> 状态：**提案**。本规格把 2026-10-18 首次启动原型的浅色“侧栏”风格定为新的设计基线，取代 PR #71 的深色 Photoshop 式方向**作为设计目标**；是否采用由维护者决定。
> 本 PR 只加文档和设计稿，不改 `src/`、DSP、CLI、数据模型、测试、AGENTS.md 或 GUIDELINES。凡标 **未实现** 的，代码里（main `ab3da19`、PR #71 `e39185c`、PR #89 `1ea78b3`）都还没有。
> 所有截图是**设计稿（design mockup）**，用 QPainter 离屏绘制，**不是交互验证**；图表数据取自 `reverbscope demo`（合成演示房间，位置 A/B），每张图底部都有标注。

## 0. 设计原则

1. **苹果的味道，不是苹果的皮肤。** 借 macOS HIG / Logic Pro / Final Cut / 系统设置的做法：标题栏与工具栏合一、全高侧栏带 vibrancy 材质、交通灯区、原生感的分段控件和弹出按钮、8 pt 节奏、克制的阴影。不复制苹果图形资源，不用 SF Symbols 文件（许可证不允许随非苹果平台应用分发，见 §16.4）。
2. **测量工具优先。** 图表区是主角（分析页占内容区宽度 ≥ 70 %、高度 ≥ 60 %），专业读数（对数频率轴、单位、网格、当前/基准角色、读数栏）一个不少。
3. **只有一层盒子。** 页面直接放在画布上；分组列表（inset grouped）是唯一的卡片层级；图表不再套卡片，只用发丝框。
4. **安全和忙碌状态看得见。** 发声时 Stop 永远可见、Esc 一次停止；被锁定的东西变灰并写原因；电平确认的理由写在禁用按钮旁边，不靠悬停。
5. **三种用户类型只换说法和默认细节，不换数字。**

### 2.2 材质（vibrancy）

- macOS：侧栏用 `NSVisualEffectView.Material.sidebar`（Qt 里可通过原生窗口句柄设置，或 `QWidget` + 半透明背景）；**未实现**。
- Windows 11：Mica / Acrylic 不可靠时，回退为 `sidebar.top → sidebar.bot` 的竖向渐变（设计稿就是这个回退）。
- 深色：侧栏比内容区亮一级（macOS 深色模式的做法），不是更暗。
- 阴影：只有三种——控件 1 px 下移 5 % 黑；弹层/工具提示 8 px 模糊 18 %；窗口/设置窗口 30 px 模糊 30 %。

## 5. 窗口与侧栏（260 px）

自上而下（y 为窗口坐标）：

1. 0–52：交通灯（x 20，直径 12，间距 20）+ 右侧“显示/隐藏侧栏” `panel-left` 16 px。标题栏可拖动区域。
2. 52–84：应用图标 20 + “ReverbScope”（headline）。
3. 96：**新测量** `plus` + 快捷键帽 ⌘N；128：**搜索测量** `search` + ⌘K（**未实现**：PR #71 没有搜索）。
4. 分节标题 caption 600 `text3`：“项目”——项目行（`folder-open`）、位置行（callout `text2`，缩进 32）、测量行（缩进 48；徽章“基准”；右侧 `triangle-alert` 表示有提醒；测量中显示 `activity`）。选中行：`sel.sidebar` 底，圆角 6，左右各留 10。
5. “最近”：`history` 14 + 名称。空状态一行“还没有测量。保存后会出现在这里。”
6. 底部（H−48 发丝线）：**设置** `settings`、**帮助** `circle-help`，右侧 **反馈** `message-square`（打开 帮助 ▸ 反馈 子菜单，见 10-18 原型）。
7. 忙碌（发声）时：新测量与设置变灰；新测量右侧换成 `lock`；悬停写“测量进行中 · 停止或结束后可用”（设计稿 04 画出了这个提示）。搜索、浏览列表仍可用。

PR #71 的“项目 / 测量 / 分析 / 对比”四个任务按钮去掉，改为：新测量 → 测量流程；点测量行 → 分析；工具栏 `git-compare` 或 ⌘0 → 对比；点项目行 → 项目总览（见 MAPPING）。

## 6. 统一工具栏（52 px）

- 左：标题（headline）+ 副标题（caption `text3`），例如“B-1 / 合成演示房间 · 位置 B”。侧栏隐藏时，交通灯和 `panel-left` 移到工具栏最左。
- 中：分段控件（分析视图 / 测量路径 / 对比视图）。分段文字 callout 500，左右内边距 10–12，选中块白底 + 5 % 阴影。
- 右：工具图标 18 px、命中区 30×30、间距 2；激活态 `accent.soft` 底 + `accent.text` 图标。
- 下沿 1 px `sep`。没有第二条应用栏、没有上下文栏、没有状态栏。
- 短暂提示（“会话已保存到 …”）进**工具栏副标题位置** 4 秒后恢复（修 LAYOUT-R2；**未实现**）。

## 7. 首页 / 空状态（设计稿 01）

- 一组内容整体垂直居中：应用图标 44 → display 标题“测一测你的录音位置” → 一句说明（body `text2`） → **composer**（640×112，圆角 18，`surface`，窗口级阴影）。
- composer：占位“拖入录音文件，或选择一种方式开始”；左下三个胶囊单选：**用音频接口** `audio-lines` / **用 DAW** `music` / **导入脉冲响应** `file-audio`（选中 = `accent.soft` 底 + `accent` 描边）；右下**录音配置胶囊**“人声配置 ▾”（`mic`）和 36 px **teal 圆形开始按钮**（`arrow-right` 20）。回车 = 开始。
- 次按钮（胶囊描边）：打开示例项目 / 打开… / 打开项目…；快捷键帽一行：⌘N 新测量 · ⌘O 打开 · ⌘K 搜索 · ⌘, 设置。
- 三步说明：连接接口或 DAW → 播放扫频并录音 → 读懂频响与余音（20 px 图标 + callout `text3`）。最下一行写当前解释方式和修改入口。
- 不是聊天框，不做 AI 文案；composer 只是“拖放区 + 路径选择 + 配置 + 开始”。

```
├──────────┴── 操作栏 64（固定，在滚动区外）：[‹ 上一步]  原因/状态 …… [继续 ⌘↩] ┤
```

- 步骤：音频接口 **连接设备 → 信号与电平 → 测量**；DAW **测试信号 → 录制说明 → 导入 → 分析**（同一组件，4 段）。步骤条居中于表单+就绪栏整组上方，节点 22 px：完成 = teal 实心 + `check`；当前 = teal 实心 + 序号；未到 = 描边圆 + 序号；锁定 = `sunken` + `lock`；运行中 = `accent.soft` + `activity`。完成段之间的连线为 teal。
- **FLOW 门控**：前一步不完整时后面的步骤节点不可点击（悬停写原因，如“请先连接音频设备”）；“继续”与 ⌘↩ 一并禁用，原因写在操作栏状态位（不只在悬停里）——第 1 步也一样（修 FLOW-03）。
- **只有一个“上一步”**（第 1 步禁用，不隐藏），没有“返回”。Esc 不等于上一步（§14）。
- 操作栏固定在滚动区外，960×640 / 1280×800 / 1440×900 都完整可见；内容对齐表单列两端（R2）。
- < 1100：侧栏隐藏；就绪检查收成工具栏右侧一个状态胶囊（“就绪 2/3 · 电平需确认”，警告色），点开是弹层列表（设计稿 10b）。

### 8.2 SAFE（电平安全，设计稿 03）

- 播放电平滑块 −40…0 dBFS：≤ −12 的安全区用 22 % teal 底并在下方标“安全区 ≤ −12 dBFS”；门槛处 1.5 px 警告色虚线；超出门槛的填充段用 `warn`；读数 `mono 500`，超门槛时为 `warn` 色。
- 超过 −12 dBFS：分组卡片底部出现**满宽警告色带**：`triangle-alert` + “高于 −12 dBFS：先调低监听音量，再勾选确认。改电平、停止或新测量都会清除确认。” + 复选框“**我已调低监听音量**”。
- 未勾选时：“继续 / 开始测量”禁用；操作栏状态位写“先勾选‘我已调低监听音量’才能继续”——**原因文字与复选框文字逐字一致**（修 SAFE-05）。
- 确认被清除的时机（全部要做）：电平**任何**改动（不只是跨门槛，修 SAFE-04，待维护者确认）、新测量（修 SAFE-02）、停止、测量完成或失败。被清除后若停在第 3 步，自动回到第 2 步并把原因写在操作栏（修 SAFE-03）。
- ≤ −12 dBFS 时复选框禁用并写“当前电平无需确认”。

### 8.3 BUSY / 测量中（设计稿 04）

- 发声时（扫频播放或录音）锁定：设置（⌘,）、打开（⌘O）、打开项目（⇧⌘O）、新测量（⌘N）、**保存（⌘S，修 BUSY-02）**、路径切换（⇧⌘1/⇧⌘2 与工具栏分段）、用户类型切换、步骤 1–2、上一步。锁定项变灰并带 `lock`；菜单里也要看得到原因（`QMenu.setToolTipsVisible(True)` 或菜单项副标题，修 BUSY-03）。
- 允许：浏览侧栏和已有测量的分析页、搜索。
- 工具栏右侧红色胶囊“● 测量中 · 6.2 s”；表单区显示进度条（确定进度 + 秒数）、实时输入波形（示意）、输入电平表（峰值读数 + −6 dBFS 警戒线）。
- **Stop**：操作栏右侧唯一的主 Stop（`crit` 底，`square-stop` + “停止” + “Esc”）。离开测量页时 Stop 移到工具栏右侧同一位置（同一动作），保证任何页面都可见；不再同时出现两个 Stop（修 FLOW-02）。
- 分析中（不可取消）：Stop 位换成不确定进度 +“分析不可取消”。

| ↑↓（瀑布） | 换切片 | **未实现** |
| ↑↓ ↩ Esc（首次启动） | 选择 / 继续 / 跳过 | 10-18 原型；**未实现** |

**Esc 优先级**（自上而下，命中即停）：
1. **发声中** → 立即停止并静音。应用级事件过滤器处理，**先于**下拉弹层、菜单、浮层；**一次 Esc 即停**，停止后顺手关闭仍开着的弹层（修 ESC-03）。发声时不允许打开模态，因此不与模态冲突。
2. **分析中** → 不停止，Stop 位提示“分析不可取消”。
3. **有模态对话框（`activeModalWidget()` 非空）或事件目标属于别的顶层窗口** → 交给对话框，按 Qt 规则关闭/取消（修 ESC-R1：#89 在这里吞掉了 Esc）。
4. 图表手势进行中 → 取消手势、恢复范围。
5. 打开的弹层 / 菜单 → 关闭。
6. 覆盖式检查器 / 侧栏 → 关闭，焦点回画布。
7. 测量向导（未发声）→ 退出到来时的页面，输入保留；不等于上一步。
8. 其他 → 无操作。
