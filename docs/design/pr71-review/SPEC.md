# PR #71 视觉规格 v2（设计稿规格，不是实现说明）

> 范围：PR #71（`e39185c`）的任务结构与分步测量 + PR #79 的专业图表视觉与密度。
> 优先级：[GUIDELINES.zh-CN.md](../../GUIDELINES.zh-CN.md) > 本规格 > PR #79 `docs/design/pro/`。
> 与准则不一致之处集中列在 §12“准则差异”，等待维护者裁决，本 PR 不改准则。
> 本文所有尺寸为逻辑像素（1×）；2× 设备按 DPR 渲染，不另定数值。

## 1. 设计原则（落到这次改版）

1. **画布第一**：分析任务里，绘图区在 960×640 下 ≥ 窗口高度 50 %，在 1440×900 下 ≥ 60 %。
2. **状态先于说明**：步骤条状态、按钮禁用原因、就绪检查代替横幅和弹框（准则 P4、§17.2）。
3. **一个含义一处出现**：视图名只在应用栏出现一次；适配只在图表工具条 + 双击 + F。
4. **数字可读**：所有数值用等宽数字，数值与单位间一个空格，负号 U+2212（准则 §13.4）。
5. **安全显性**：发声时，Stop 永远可见、Esc 永远先停止（准则 P9、§11.5）。

## 2. 网格与间距

- 4 pt 基础网格：`space.1=4, 2=8, 3=12, 4=16, 5=20, 6=24, 8=32`（准则 §13.5）。
- 页边距：阅读型视图 24（≥ 1280 时 32）；图表视图 0（画布贴边，图表工具条内边距 8）。
- 区块间距 16（PR #71 为 24，见 AI-01）；表单行距 12；同组控件间距 8。

### 9.2 Esc 优先级（自上而下，命中即停止向下传递）

1. **发声中（扫频 / 录音）** → 停止并静音。由 `QApplication` 级事件过滤器处理，**先于**任何下拉弹层、浮层或模态；
   测量中本就不允许打开模态（BUSY-01），所以这条不会和模态冲突。
2. **分析中（不可取消）** → 不停止；任务条短暂显示“分析不可取消”。
3. **图表手势进行中**（框选、拖动光标）→ 取消手势，恢复手势前范围。
4. **打开的下拉 / 菜单 / 工具提示弹层** → 关闭（Qt 默认行为）。
5. **覆盖式检查器 / 列表（< 1440）或其他浮层** → 关闭，焦点回到画布。
6. **测量向导（未发声）** → 退出到来时的视图，已填输入保留；**不等于“上一步”**。
7. **其他** → 无操作，不提示。

模态对话框内的 Esc 仍按 Qt 规则触发“取消”（`setEscapeButton` 已正确使用，`ui/main_window.py:93`、`:502`）。
