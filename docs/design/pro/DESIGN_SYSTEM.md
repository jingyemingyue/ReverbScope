## 0. 定位

### 0.1 一句话

**图表是主角，数据胜过装饰。** ReverbScope 是一台桌面测量仪器：左边选测量，中间看图，右边看参数和检测结果，底部随时开始或停止测量。界面保持现在的克制、干净，但信息密度提高到“专业工具”的水平。

### 0.2 原则

| # | 原则 | 落地方式 |
| --- | --- | --- |
| P1 | 图表优先 | 中间图表区占窗口宽度 60–70 %；窗口变窄时先收侧栏，**永远不压缩图表**（最小 640 px） |
| P2 | 数据胜过装饰 | 不用大圆角卡片、渐变、插画、聊天式布局、超大标题；分组靠 1 px 分隔线和小标题 |
| P3 | 一种数字字体 | 所有数值（刻度、读数、表格、列表里的值、检查器）用 IBM Plex Mono；文字用 IBM Plex Sans + 思源黑体 |
| P4 | 诚实 | 有效性按 §13.3 标注；不可靠的值加括号和 “?”；扫频范围外、未参与分析的区域画斜线；**未实现的功能在界面上标“未实现”**（设计稿）或根本不出现（产品） |
| P5 | 平台习惯 | macOS：原生菜单栏、统一标题栏/工具栏、侧栏、⌘ 快捷键、sheet、popover；Windows/Linux 用 Ctrl，菜单栏在窗口内 |
| P6 | 两种密度，一套组件 | “普通”模式引导式、少参数；“专业”模式全参数、图表工具、数据表。两者共用同一套 token 和组件，只是显示的东西不同 |
| P7 | 安全显性 | 测量中停止按钮始终在底部控制条上，Esc 永远有效（准则 P9） |

参考对象（REW、Smaart、iZotope RX、Logic Pro、Apple HIG）**只学原则，不复制资产**，规则同 [GUI_REFERENCE_AUDIT.md](../GUI_REFERENCE_AUDIT.md)：细网格、清楚的对数轴、统一的曲线色板、等宽数据字体、紧凑工具条——这些是测量软件的通用惯例，没有读取或改编任何一款软件的代码、图标、截图或配色表。

### 1.3 用色规则

1. **曲线色跟着测量走**：`series_1…8` 按测量列表的顺序分配，切换视图不变（现有 `ENTRY_COLORS` 的行为）。当前测量实线 2.2 px；叠加 1.6 px、90 % 不透明；**基准一律虚线**（5-3 dash）。黑白打印靠线型区分：实线、虚线、点线、点划线循环（现有 `DASHES`）。
2. **频带用顺序色阶** `band_1…8`（63 Hz → 8 kHz）。浅色取 viridis 0–0.92 并压暗到 ≥ 3:1，深色取 0.22–1.0 并提亮到 ≥ 3:1。宽带曲线用 `text` 色、2.0 px。
3. **状态色（good / warn / bad / info）永远不画曲线**，只用于图标、徽章、文字、横幅。注释性的标记（共振候选的高亮带）用 `info` 的 10 % 底色，不用实线。
4. **强调色每屏最多一个实心按钮**（主操作“开始测量”）；其余强调色只出现在选中态、焦点环、链接文字（`accent_fg`）。
5. **“未实现”徽章**专用 `planned` 紫色（设计稿和开发者版用）。正式发行版里未实现的功能不出现，不显示徽章。
6. 图表区底色 `plot_bg` 与面板底色分开：浅色同为白色，深色比面板更深（#161719），让曲线“浮”在仪器屏上。

### 1.5 对比度

`contrast_pro.py`（WCAG 2.2 AA）检查 162 对：文字 ≥ 4.5:1（正文、次要、三级文字在全部 10 种底色上；强调色文字；状态文字；刻度文字；光标旗标），非文字 ≥ 3:1（全部曲线色与频带色、光标、坐标轴线、输入框边框、焦点环）。**0 项未通过**，结果表见 [CONTRAST.md](CONTRAST.md)。为了过检，相对初稿改了：`faint` 浅色 #63666a→#5f6266、深色 #9a9ca1→#a3a5aa；`planned` 浅色 #6b5bd2→#5b4bc4；新增 `accent_fg`（强调色作文字时用，浅色 #136a73）。

### 2.3 数字写法（沿用 CLI，准则 §13.4）

- 负号用 U+2212（`−87.1`），正值显式写 `+`（`+10.1 dB`）。
- 数字和单位之间一个空格：`0.51 s`、`−87.1 dBFS`、`91 %`。
- 频率：< 1000 写 `109.7 Hz`，≥ 1000 写 `1.00 kHz`（读数）或 `1k`（刻度）。
- 表格数字右对齐，同列同小数位；单位放在列头 `T30 (s)`，不放在格子里。
- 不可靠：`(0.69)?`，`warn` 色，悬停显示原因（数据来自 `DecayMetric.reason`）。未计算：`—`。

### 5.2 1440×900 时的分配

### 5.3 断点与折叠顺序（窗口宽 W）

规则：**检查器停靠的条件是 `W ≥ 1280` 且 `W − 列表宽 − 检查器宽 − 2 ≥ max(720, 0.60·W)`**（第二条只在用户把侧栏拖宽时起作用）。断点：

| 窗口宽 W | 列表 | 检查器 | 图表宽（默认） | 其他 |
| --- | --- | --- | --- | --- |
| ≥ 1680 | 248 | 340 停靠 | ≥ 1090（≈ 65 %） | — |
| 1280–1679 | 220 | 288 停靠 | 770–1169（60–70 %） | — |
| 1024–1279 | 220 | **隐藏**；⇧⌘→ 以浮层打开（覆盖图表右侧，不挤压） | 803–1058 | 控制条去掉“输出”和扫频摘要；工具条复选框收进“显示选项”popover |
| 960–1023 | **48 图标栏** | 隐藏（浮层） | 911–974 | 视图切换只留 频率响应/ETC/RT60/瀑布图 + “⋯”；控制条只留方式、采样率、位置 |
| < 960 | 不允许（`setMinimumSize(960, 640)`，现有） | | | |

折叠顺序（变窄）：① 检查器 → 浮层；② 列表 → 图标栏；③ 工具条文字 → 图标；④ 视图切换收进 “⋯”；⑤ 控制条次要控件收进“设置…”。变宽时倒序恢复。**用户手动关掉的面板不会被自动打开**（“自动隐藏”和“用户隐藏”是两个状态）。

纵向（窗口高 H）：H < 760 时，副图（差值、分频带表）默认高度从 30 % 降到 24 %，表格只显示前 5 行加“展开”；H = 640 时主图高度仍 ≥ 320。

## 9. 普通模式与专业模式

用户类型沿用已设计的三类：**普通用户 → 普通模式**；**音乐人 → 专业模式 + 混合措辞**；**专业人士 → 专业模式**。工具栏上可以随时切换（⇧⌘P），记住在设置里。详细差异表见 IMPLEMENTATION_SPEC §10。要点：

- 普通模式：视图只有 结论 / 频率 / 混响 / 反射；图上有编号注释和一句“这张图说明什么”；检查器是“解读”（测量怎么样 → 房间的三件事 → 下一步）；控制条一行摘要 + “更改…”；列表不显示数值。
- 专业模式：全部视图、指针工具、布局、全部参数、数据表、读数栏。
