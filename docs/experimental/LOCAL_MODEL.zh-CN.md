# 本机说明模型（实验）

不属于 0.5 稳定版，也不属于候选发布版。测量核心不会导入它。

## 训练了什么

`guided-clause-v1` 只用离线目录做梯度下降。训练集里没有录音、没有用户测量、也没有从网络下载的基座模型。

它不能自由写句子。每一步只能选择这条诊断、这种语言里已经核准的目录句子，或者停止。说明长度决定用短、中、还是完整计划。测量数字既不是输入，也不在词表里。安全探针和原来的说明校验器会拒绝数字，以及把桌面说成确定原因、或要求断开地线这类句子。

其他语言仍然回退到英文目录，不会假装已经翻译。

## 安装

文件随这个实验版本提供，但安装之前不会使用，也不会自动下载。

桌面：设置 → 智能诊断助手 → 安装本机说明模型。

命令行：

```text
reverbscope guided --result session-folder --install-local-model
```

这会复制文件、核对目录指纹，并改用本机说明。不做这一步时，默认仍是内置说明。隐私模式仍可使用这个模型，但不会因此调用云端。

目录如果变了，指纹对不上，模型会拒绝加载。需要时再运行：

```text
python -m reverbscope.experimental.guided.local.train
```
