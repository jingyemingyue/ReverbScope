# 隐私（实验性导引）

下面五件事彼此独立。打开一件不会顺便打开另一件。

| 能力 | 离开这台设备的内容 |
| --- | --- |
| 内置说明 | 没有。不联网。 |
| 本地模型 | 没有。模型和测量都留在本机。不会自动下载模型。 |
| 云端模型（你自己的密钥） | 一份经过清理的诊断摘要，从本机直接发给你选择的服务商。密钥不会发给 ReverbScope 的服务器。 |
| 在线资料 | 只有通用技术问题，没有测量数据。默认关闭。 |
| 帮助改进 | 默认关闭。可分别选择匿名使用统计、通用硬件兼容结果或匿名崩溃类别。 |

## 永远不会自动上传

密钥、原始音频、脉冲响应波形、会话文件、截图、完整日志、个人备注、主目录、用户名、精确位置、房间名、序列号或唯一设备标识。填写密钥不会打开遥测。打开遥测也不会带上密钥。

## 隐私模式

`reverbscope --privacy-mode` 在本次运行中禁止云端模型、在线查询、遥测和崩溃上传。内置说明和已经下载的本地模型仍可使用。已经保存的密钥不会被删掉，也不会被调用。
