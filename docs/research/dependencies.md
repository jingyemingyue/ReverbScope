# ReverbScope dependency license audit

- Project: ReverbScope (Python >= 3.12, intended license Apache-2.0; distributed as PyPI sdist/wheel and later as a frozen PySide6 desktop app for macOS / Windows / Linux).
- Audit date: 2026-09-17.
- Method: for every package, (1) PyPI JSON API read for latest stable version, `License` field, `License-Expression`, `License-File` list and classifiers; (2) the upstream repository LICENSE file was fetched from the raw GitHub / code.qt.io URL and its first line + copyright line quoted; (3) for packages that ship native code, the actual macOS (arm64 / universal2, cp312 or abi3) wheel from PyPI was downloaded and its contents listed (`.dylibs`, frameworks, plugins, and every LICENSE / COPYING / NOTICE file inside the wheel). Linux x86_64 cp312 wheels of numpy/scipy/soundfile/sounddevice/matplotlib/Pillow were opened on 2026-09-22 (`scripts/audit_wheel_contents.py`); Windows win_amd64 cp312 wheels of those packages plus the sounddevice 0.5.6 wheel were downloaded the same day and listed. See DEPENDENCIES.md §6.
- Versions audited are the ones installed in the project venv (confirmed identical to PyPI latest stable on the audit date): numpy 2.5.3, scipy 1.18.1, soundfile 0.14.0, sounddevice 0.5.6, matplotlib 3.11.2, PySide6 6.11.2, shiboken6 6.11.2, cffi 2.1.1, pycparser 3.0, contourpy 1.4.0, cycler 0.12.1, fonttools 4.65.0, kiwisolver 1.5.1, packaging 26.3, pillow 12.3.0, pyparsing 3.3.2, python-dateutil 2.9.0.post0, six 1.17.0, pytest 9.1.1, pytest-cov 7.1.0, ruff 0.16.8, mypy 2.3.1.
- Compatibility legend: **Yes** = permissive, only notice retention; **Yes with obligations** = compatible but concrete redistribution duties (notice files, LGPL relinkability, credit lines); **Risk** = needs a decision before shipping.

Removes the LGPL obligations for Qt itself; the FAQ notes that "some third-party components like Chromium may retain their open source licenses". Not needed for ReverbScope.

**Does an Apache-2.0 app that uses unmodified PySide6 wheels via normal `import PySide6.QtWidgets` satisfy LGPL-3.0?** Yes, provided the packaging keeps the following true:
- Qt and PySide6 are loaded as separate shared libraries (`PySide6/Qt/lib/*.framework`, `*.abi3.so`, `libpyside6*.dylib`, `libshiboken6*.dylib`) through the normal Python import mechanism — this is dynamic linking in the LGPLv3 §4(d)(1) sense ("a suitable shared library mechanism ... that (a) uses at run time a copy of the Library already present on the user's computer system, and (b) will operate properly with a modified version of the Library that is interface-compatible"). A user can drop in a rebuilt Qt 6.11.x / PySide6 6.11.x and the app keeps working.
- Do not statically link Qt into a single binary, do not encrypt/obfuscate the bundled Qt libraries, and prefer one-directory / `.app` bundle layouts (PyInstaller `--onedir`, briefcase, py2app) over single-file executables that hide the Qt libraries; if a one-file build is used, document how to extract and replace the Qt libraries so that §4(d) is still met.
- ReverbScope's own source is public under Apache-2.0, so the "relink/rebuild the application" requirement is trivially satisfiable (the user can re-run the build); still ship the notices below.
- ReverbScope must not import any GPL-only module (QtCharts, QtDataVisualization, QtGraphs, QtLottie, QtVirtualKeyboard, QtQuick3D, QtQuickTimeline, QtHttpServer, QtNetworkAuth, QtShaderTools). Plots are done with matplotlib, so this is met; keep it in the coding guidelines. Consider stripping the GPL-only frameworks (QtLottie*, QtQuickTimeline* from Essentials; all of Addons) from the frozen bundle to reduce size and ambiguity.
- No EULA term may prohibit modification of, or reverse engineering for debugging, the Qt parts; the Apache-2.0 license contains no such term, but check any app-store or installer EULA text.

**Files that must ship with a frozen binary** (the PyPI wheels do NOT contain any license file — verified for `pyside6`, `shiboken6` and `pyside6_essentials` 6.11.2 — so these have to be added in the packaging step):
1. `LGPL-3.0-only.txt` and `GPL-3.0-only.txt` copied from the pyside-setup repository `LICENSES/` directory at tag 6.11.2 (LGPLv3 §4(d) requires both), in a `third_party_licenses/PySide6/` (or `licenses/qt/`) folder next to the app and reachable from the About dialog.
2. A prominent notice, in the About dialog and in the README/NOTICE shipped with the app, e.g. "This application uses Qt 6.11.2 and PySide6 6.11.2, Copyright (C) The Qt Company Ltd. and other contributors, licensed under the GNU Lesser General Public License v3 (LGPL-3.0-only). Source code: https://download.qt.io/official_releases/qt/6.11/6.11.2/ and https://code.qt.io/cgit/pyside/pyside-setup.git/. The Qt libraries are shipped as separate shared libraries in <path> and may be replaced with a modified, interface-compatible version."
3. The Qt third-party attributions for the modules used (QtCore/QtGui/QtWidgets: PCRE2, zlib, libpng, libjpeg-turbo, HarfBuzz, FreeType (FTL credit line), SQLite, Unicode data, MD4C, simdutf), taken from https://doc.qt.io/qt-6/licenses-used-in-qt.html for Qt 6.11.
4. The PySide6 `LICENSES/` directory as a whole (all eight files) is the simplest way to satisfy 1 and cover shiboken6; include the `Qt-GPL-exception-1.0.txt` only for completeness (it concerns Qt-tool-generated code).
5. Nothing needs to be added to the PyPI sdist/wheel of ReverbScope itself for Qt, because ReverbScope's own distribution does not contain Qt; the obligations attach to the frozen desktop app that bundles the wheels.
