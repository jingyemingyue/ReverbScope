# Application icon

A scope: a lens with a graticule, a decaying trace with a sharp attack (an
impulse response) and two fading echoes of it for the reverberation, on the
accent teal of the interface. Original artwork for this repository, under the
repository's Apache-2.0 licence; no third-party icon, font or image is in it.

| File | Used by |
| --- | --- |
| `reverbscope.svg` | Source, full detail (64 px and up) |
| `reverbscope-small.svg` | Source for 32 px and below: no graticule or echoes, heavier strokes |
| `ReverbScope.icns` | macOS: `ReverbScope.app` (`packaging/reverbscope.spec`, `BUNDLE`) |
| `ReverbScope.ico` | Windows: `reverbscope.exe`, `reverbscope-gui.exe` and the setup program (`packaging/windows/reverbscope.iss`) |
| `reverbscope.png` | Linux: copied next to the launchers with `packaging/linux/reverbscope.desktop` |

The window icons the running app sets are in `src/reverbscope/ui/icons`
(`reverbscope.ui.widgets.app_icon`).

Everything here is generated by `scripts/make_app_icon.py`: change the
drawing there, then follow its docstring (write the SVGs, render them at
1024 px, export, `iconutil -c icns`). Do not edit the exported files by hand.
