=== reverbscope --help
usage: reverbscope [-h] [--version] [--lang LANG] [--format {text,json}]
                   [--color WHEN] [--style STYLE] [--backend NAME]
                   [--copy-recording | --no-copy-recording] [-v] <command> ...

ReverbScope: an open-source, DAW-independent recording environment analyzer.

commands:
  Get started
    demo        try ReverbScope with synthetic data: no audio hardware needed
    gui         start the desktop GUI (needs PySide6; the desktop download
                includes it)
  Measurement
    sweep       write the ESS test signal WAV (+ JSON sidecar)
    analyze     analyse a recording made with the sweep
    devices     list audio devices (Standalone Mode)
    measure     Standalone Mode: play the sweep and record the microphone
    analyze-ir  analyse an impulse-response WAV from another tool
  Results
    show        print a saved session or comparison.json report, or list
                sessions
    compare     compare two saved sessions
    project     project folders (one room, several positions)
    export      export curves through an exporter
    session     session folder tools
  Settings
    config      show or change the settings (the same settings.json as the
                desktop app)
  Diagnostics
    doctor      print an environment report for bug reports and debugging
    schema      print a shipped JSON Schema

options:
  -h, --help            show this help message and exit
  --version             show program's version number and exit
  --lang LANG           interface language for this command (en, zh_CN);
                        reverbscope config language keeps one
  --format {text,json}  text report or JSON on stdout (diagnostics stay on
                        stderr)
  --color WHEN          colour in the terminal: auto (default; off for pipes,
                        files and NO_COLOR), always, never
  --style STYLE         frames around reports: auto (default; the style
                        setting, else boxed on a wide terminal and plain in a
                        pipe), boxed, plain
  --backend NAME        audio backend for Standalone Mode: portaudio (default)
                        or fake
  --copy-recording, --no-copy-recording
                        copy the raw recording into the session folder
                        (default: user settings)
  -v, --verbose         debug logging, and tracebacks on errors

examples:
  reverbscope demo
  reverbscope sweep --out sweep.wav
  reverbscope analyze --recording take.wav --sweep sweep.wav --out session-1
  reverbscope compare session-1 session-2

Run a command with --help for its options, for example:
  reverbscope measure --help

中文界面：reverbscope config language zh_CN

=== reverbscope analyze --help
usage: reverbscope analyze --recording WAV --sweep FILE [options]

analyse a recording made with the sweep

required:
  --recording WAV       recorded WAV (any length, untrimmed)
  --sweep FILE          sweep WAV or its .reverbscope-sweep.json sidecar

options:
  -h, --help            show this help message and exit
  --out DIR             directory for session.json, result.json, IR WAV

analysis:
  --channel N           recording channel to analyse (0-based)
  --smoothing N         fractional-octave smoothing 1/N (0 = off) (default: 6)
  --profile {acoustic_guitar,choir,drums,generic,room_mic,vocal,voiceover}
                        recording profile that shapes the interpretation
                        (default: user settings)

session notes (stored in session.json):
  --room TEXT           room name (metadata)
  --position TEXT       measurement position (metadata)
  --mic TEXT            microphone name (metadata)
  --notes TEXT          free-text notes (metadata)

placement (optional tape measurements):
  --speaker-distance M  straight line from the loudspeaker to the microphone
                        capsule (m), measured with a tape. Without it no
                        geometry can be derived from the reflections
  --mic-height M        microphone capsule above the first solid horizontal
                        surface below it (m) -- the desk top at a desk,
                        otherwise the floor. Needs --speaker-distance
  --temperature C       air temperature (C); 20 C is assumed, and reported as
                        assumed, without it

output:
  --no-curves           omit curves from result.json
  --json                deprecated: use reverbscope --format json

loopback (optional):
  --loopback WAV        separate loopback WAV from the same take (same sample
                        rate)
  --loopback-channel N  0-based loopback channel: of --loopback when it is
                        given, otherwise of the recording

examples:
  reverbscope analyze --recording take.wav --sweep sweep.wav
  reverbscope analyze --recording take.wav --sweep sweep.wav --out session-1
  reverbscope analyze --recording take.wav --sweep sweep.wav --loopback-channel 1

=== reverbscope measure --help

Standalone Mode: play the sweep and record the microphone

  --out DIR             session directory (created)

  --mic-height M        microphone capsule above the first solid horizontal

=== reverbscope config --help
usage: reverbscope config [KEY [VALUE]] [options]

show or change the settings (the same settings.json as the desktop app)

positional arguments:
  KEY         the setting to show or change; without it every setting is
              listed
  VALUE       the new value; auto goes back to the default

options:
  -h, --help  show this help message and exit

settings:
  language         zh_CN, en, or auto (follow the system)
  profile          acoustic_guitar, choir, drums, generic, room_mic, vocal,
                   voiceover, or auto (generic)
  backend          portaudio, fake, or auto (PortAudio)
  output-folder    an existing folder, or auto (none)
  copy-recording   on or off (auto: on)
  developer-tools  on or off (auto: off; a source or pip install always has
                   them)
  theme            system, light or dark (the desktop app only)
  style            boxed, plain, or auto (frames on a terminal at least 48
                   columns wide; never in a pipe)

examples:
  reverbscope config
  reverbscope config language zh_CN
  reverbscope config language auto
  reverbscope config profile vocal
